# Room Booking

Учебный сервис бронирования переговорок на Spring Boot.

## Стек

- Java 17, Spring Boot 4.1.2
- Spring Web, Spring Data JPA, Bean Validation
- H2 (in-memory), JUnit 5, Mockito

## Запуск
`./mvnw spring-boot:run`


Сервис поднимается на `http://localhost:8080`.

## Эндпоинты

| Метод | Путь | Описание | Ответ |
|---|---|---|---|
| GET | /hello?name=... | Проверка DI | 200, текст |
| GET | /rooms | Список комнат | 200, JSON-массив |
| POST | /rooms | Создать комнату | 200, JSON с id |
| POST | /bookings | Создать бронь | 200, JSON с id |

Тело `POST /rooms`: `{"name":"Переговорка 1"}`.
Тело `POST /bookings`: `{"roomId":1,"startTime":"2026-11-03T10:00:00","endTime":"2026-11-03T11:00:00"}`.

## Ошибки

| Код | Когда |
|---|---|
| 400 | Пустое или отсутствующее поле, конец брони раньше начала |
| 404 | Комната с таким id не найдена |
| 409 | Комната уже занята в это время |

## Тесты

`./mvnw test`


Unit-тесты сервиса (Mockito) и интеграционные тесты HTTP-слоя (MockMvc).

## Ограничения

- Данные хранятся в памяти: после перезапуска пропадают.
- Проверка пересечений не защищает от одновременных запросов (гонка между проверкой и записью).
- Бронь возвращается с кодом 200, а не 201 Created.
- Ответ содержит сущность `Booking` напрямую, DTO для ответа не сделан.

Ограничения записаны намеренно: их полезно уметь назвать на собеседовании.
